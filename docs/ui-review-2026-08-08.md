## Findings（按严重度排序）

### HIGH

| # | Domain | Location | Before | After | Why |
| --- | --- | --- | --- | --- | --- |
| 1 | Accessibility | `App.tsx:495`、`SettingsPanel.tsx:115-123` | 搜索框仅 placeholder、select 无 `<label for>`（placeholder 不是 label） | 添加 `<label htmlFor="skill-search">`；select 用 `<label htmlFor>` 关联 | 屏幕阅读器无法获知控件用途；placeholder 输入后消失 |
| 2 | Accessibility | `ProjectNav.tsx:112,119`、`ToolsSection.tsx:250` | `<button>✎</button>`、`<button>×</button>` 仅 unicode 图标无 aria-label | 加 `aria-label={t("editProject")}` / `aria-label={t("deleteTool")}`，图标 `aria-hidden="true"` | 图标按钮无可访问名称，读屏输出"✎"或空白 |
| 3 | Accessibility | 全部 7 个 modal（`*.tsx` 中 `modal-overlay`） | `<div className="modal-overlay">` 无 `role="dialog"`、无 `aria-modal`、无焦点圈定、无 Esc 关闭 | `role="dialog" aria-modal="true"` + 焦点 trap + Esc 处理 + 打开时聚焦、关闭后归还焦点 | 键盘用户可 Tab 出模态框；读屏无法感知对话框边界 |
| 4 | Accessibility | `App.css` `.btn`、`.tab`、`.project-btn` | 无任何 `:focus-visible` 样式；`input` 聚焦仅 `outline:none`+box-shadow | 全局 `:focus-visible { outline: 2px solid var(--accent); outline-offset: 2px; }` | 键盘导航无可见焦点环 |
| 5 | Colors | `App.css:16,35,86` | `--accent:#c47f1e` + 白字按钮文字 3.28:1；`--text-muted:#9999aa` 在 `#fafaf8` 上 2.68:1 | 加深 accent 至 ≥4.5:1（如 `#a56a14` 系）或按钮改深字；`--text-muted` 加深至 `#6f6f80`（4.5:1+） | 11 组实测中 7 组低于 AA 4.5:1，主按钮与全部次要文字不达标 |
| 6 | Accessibility | `ToastContainer.tsx:9-14` | toast 容器无 `role="status"`/`aria-live` | 容器 `role="status" aria-live="polite"` | 动态 toast 不向读屏播报 |

## Considered but Rejected

| Candidate | Rejected because |
| --- | --- |
| 引入 Tailwind/组件库统一 | 项目为手写 CSS token 体系且已较完整，引入新栈收益低于迁移成本 |
| 全面切换 OKLCH | 项目为 hex/rgba token，better-colors 规则要求保留既有表示法，只修对比度值 |
| 拆分 App.css 为多文件 | 是维护性优化非用户可见问题，标注为路线图建议而非 finding |
| 移除 noise 纹理 overlay | 设计意图（质感），非错误；仅在性能敏感时考虑移除 |
| 所有文字加粗提升对比 | 治标不治本，应从 token 层修复 |

## 优化路线图（建议）

**P0 · 无障碍与对比度（1-2 天）**
1. 修复 token：`--accent` 加深至 ≥4.5:1（或主按钮改用深字）、`--text-muted` 提至 `#6f6f80` / 暗色 `#7a7a8e`
2. 全局 `:focus-visible` 焦点环
3. 图标按钮补 `aria-label` + `aria-hidden`
4. 所有 modal 加 `role="dialog" aria-modal` + Esc + 焦点 trap

**P1 · 一致性与健壮性（2-3 天）**
5. i18n 补全（Market 表头、方向箭头、old/new）
6. 字体本地打包，消除远程依赖
7. toast 加 `aria-live="polite"`
8. action-bar 分组重组（主操作 / 筛选分开）

**P2 · 视觉打磨（按节奏）**
9. 建立字号 scale，清理 10-11px 碎片
10. unicode 图标 → SVG 图标组件
11. `transition:all` → 明确属性
12. 列表视图行内操作收起为行悬停/更多菜单，降低密度
